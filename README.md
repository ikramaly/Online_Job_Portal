# Online Job Portal (Jivika) – Frontend

A job portal frontend built using React.js, JavaScript, Tailwind CSS, and Vite.

## Features
- Responsive user interface
- Job listings and job-related pages
- Login and registration UI
- React component-based architecture
- Client-side navigation

## Tech Stack
- HTML
- CSS
- React.js
- JavaScript
- Tailwind CSS
- Vite
- React Router

## Installation & Setup

```bash
git clone https://github.com/ikramaly/Online_Job_Portal.git
cd Online-Job-Portal
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Note
This repository contains only the frontend. Features requiring backend APIs, authentication, or database operations will need a compatible backend.
